# Сайт дизайнера интерьеров — инструкция

## Как открыть
Двойной клик по **index.html** — сайт откроется в браузере. Интернет не нужен
(без него подгрузятся системные шрифты вместо фирменных — верстка не сломается).

## Файлы
```
Сайт дизайнера\
├─ index.html          ← весь текст сайта
├─ css\styles.css      ← цвета, шрифты, отступы
├─ js\main.js          ← меню, анимации, просмотр фото, форма
└─ img\
   ├─ portrait.png     ← портрет (фон уже вырезан, водяной знак убран)
   └─ portfolio\       ← сюда кладутся фото проектов
```

## Что обязательно заменить
Откройте **index.html** в «Блокноте» (или лучше — в Notepad++/VS Code).
Все места помечены комментариями `<!-- ЗАМЕНИТЕ: ... -->`.
Удобнее всего через «Найти и заменить» (Ctrl+H):

| Найти | На что заменить | Сколько раз встречается |
|---|---|---|
| `Имя Фамилия` | настоящее имя | 5 |
| `ИФ` | инициалы для логотипа | 2 (в `<title>`-иконке и в шапке) |
| `+79000000000` | телефон без пробелов, для ссылки | 2 |
| `+7 900 000-00-00` | телефон как он показывается | 2 |
| `mail@example.com` | почта | 3 |
| `https://t.me/username` и `@username` | Telegram | по 1 |
| `https://wa.me/79000000000` | WhatsApp (номер без «+») | 1 |

Дальше по тексту замените:
- **цифры на первом экране** — стаж, количество проектов, метраж;
- **текст «Обо мне»** — 3 абзаца своими словами;
- **названия проектов** в портфолио (ЖК, площадь, стиль, год);
- **цены** в блоке «Стоимость»;
- **город** в контактах;
- **год** в подвале.

## Как устроено портфолио
Сейчас на сайте 3 проекта, фото скачаны из ваших папок на Google Диске:

```
img\portfolio\blyukhera\      Квартира на Блюхера (37 м²)
img\portfolio\centr\          Двушка в историческом центре + «было — стало»
img\portfolio\studia\         Студия для студентки (25 м²)
```

В каждой папке по 8 кадров, у каждого два файла:
- `01.jpg` — большой, открывается при клике во весь экран;
- `01-thumb.jpg` — маленький, из него собрана страница (чтобы грузилась быстро).

Первый кадр (`01`) — обложка проекта, остальные идут лентой миниатюр.

### Заменить фото
Положите новый файл с тем же именем — и всё. Главное: менять **оба** файла
(большой и `-thumb`), иначе в галерее откроется старый кадр.

### Добавить кадр в проект
В `index.html` найдите нужный проект и скопируйте внутри `.project-strip`
одну строку `<button type="button" class="strip-item">…</button>`,
поменяв номер файла и текст в `alt`. Не забудьте поправить надпись
`8 фото` в блоке `.project-count`.

### Добавить новый проект
Скопируйте целиком блок `<article class="project reveal" data-title="…">…</article>`,
поменяйте название, описание, список фактов и пути к фото.
Обложки чередуются лево-право автоматически.

Рекомендации к файлам: большой кадр — ширина ~1600 px и вес до 500 КБ,
миниатюра — ширина 800 px и вес до 150 КБ.

### Блок «было — стало»
Есть только у «Двушки в историческом центре» — только для неё нашлись
нормальные фотографии до ремонта (папка «Было» на Диске).

Кадры «до» лежат там же: `before-01.jpg` … `before-04.jpg` (плюс `-thumb`).
Справа в каждой паре стоит тот же файл, что и в ленте проекта, — отдельно
его копировать не нужно.

Это **отдельная галерея**: у блока свой `data-gallery`, поэтому кадры «до»
не попадают в основную ленту проекта. Если добавляете пару — копируйте
целиком блок `<div class="ba-pair"> … </div>` и меняйте пути и подпись
в `.ba-caption`.

Чтобы сделать такой блок у другого проекта, скопируйте весь
`<div class="beforeafter" data-gallery="…"> … </div>` внутрь его `<article>`
(после `</div>` закрывающего `.project-info`) и поменяйте название галереи.

### Что стоит поправить в текстах портфолио
- у «Двушки в историческом центре» не указаны площадь и год —
  добавьте в строку `.project-meta`;
- проверьте пары «было — стало»: они составлены по типу помещения,
  какая-то может не совпасть с реальной комнатой;
- проверьте формулировки в списках фактов: они собраны по вашим PDF-описаниям
  и по фотографиям, что-то можно уточнить.

## Как поменять цвета
В начале `css\styles.css` есть блок `:root` — там все цвета одним списком.
Например, `--accent: #A08963;` — это тёплый латунный акцент (полоски, цифры,
кнопки при наведении). Поменяйте значение — изменится по всему сайту.

## Форма заявки
Сайт лежит файлом на компьютере, поэтому форма не отправляет письмо сама:
по кнопке открывается почтовая программа с уже заполненным письмом.
Когда сайт переедет на хостинг, форму можно подключить к любому сервису
(Formspree, Getform) или к боту в Telegram.

## Когда захотите выложить сайт в интернет
Нужны две вещи: домен и хостинг. Проще всего:
1. **GitHub Pages** — бесплатно, адрес вида `имя.github.io`;
2. любой обычный хостинг — просто скопировать туда всю папку целиком;
3. отдельно купить домен (например, `.ru` — около 200–400 ₽/год).

Скажите — помогу с публикацией.
